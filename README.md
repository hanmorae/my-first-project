# 🎯 숫자 맞히기 게임

1부터 100 사이의 숫자를 맞히는 간단한 웹 게임입니다.

## 플레이 방법
1. `index.html` 파일을 웹 브라우저로 엽니다.
2. 숫자를 입력하면 정답보다 큰지 작은지 알려줍니다.
3. 최대한 적은 횟수로 맞혀 보세요! 최고 기록은 브라우저에 저장됩니다.

# ☀️ 오늘의 정보 대시보드

`dashboard/` 폴더에 있는, 자주 보는 정보를 한 화면에 모은 페이지입니다.

- **날씨** (Open-Meteo): 기온, 강수확률, 강수량, 습도, 바람. 지역을 고르거나 "내 위치"를 쓸 수 있어요.
- **환율**: 원/달러, 원/100엔
- **지수**: 코스피, 코스닥, 나스닥, 다우존스

환율과 지수는 GitHub Actions(`.github/workflows/markets.yml`)가 약 1시간마다 Yahoo Finance에서 받아
`dashboard/data.json`에 저장합니다. 실시간 시세는 아닙니다.
